## Roofline analysis exposes low arithmetic intensity

The paper presents the first roofline analysis of Ising workloads and shows that their arithmetic intensity is low. A spin update reads a low-reuse stream of couplings, indices, and bias data. The cache may retain neighbor states, although the coupling stream can evict them. Arithmetic intensity remains low as graph degree rises because operations and bytes grow together.

On-chip residency marks the main performance crossover. When the coupling working set fits in the fast tier, a streaming datapath can feed every processing element from private local memory. When the working set spills, measurements show that sweep time rises sharply as memory service moves onto the critical path.

Storage choices determine where this crossover occurs. Coupling precision changes the footprint but must still cover the range required by the accumulated local field. Sparse format also matters: CSR uses inexpensive addressing, while ELLPACK provides coalesced access and a smaller footprint on regular graphs. The best choice changes as the kernel moves from latency-bound to bandwidth-bound.

Peak arithmetic throughput therefore provides a poor design guide. A GPU may offer ample floating-point capacity yet spend most of each sweep moving a low-reuse stream. The FPGA implementation places local memory beside each processing element and turns the same update into a fixed-rate pipeline.
