## Roofline analysis exposes low arithmetic intensity

The paper presents the first roofline analysis of Ising workloads. Each spin update streams couplings, indices, and bias data with little reuse. Neighbor states may remain in cache, but the coupling stream can evict them. Arithmetic intensity stays low even when graph degree rises because operations and bytes grow together.

On-chip residency marks the main performance crossover. If the coupling working set fits in the fast tier, a streaming datapath can feed every processing element from private local memory. Measurements show that sweep time rises sharply once the working set spills and memory service moves onto the critical path.

Storage choices decide where that cliff occurs. Coupling precision changes footprint but cannot be narrowed past the range required by the accumulated local field. Sparse format also matters: CSR has cheap addressing, while ELLPACK gives coalesced access and a smaller footprint on regular graphs. The winning choice changes as the kernel moves from latency-bound to bandwidth-bound.

This is why peak arithmetic throughput is a poor guide. A GPU may have ample floating-point capacity and still spend most of a sweep moving a low-reuse stream. The FPGA implementation provisions local memory beside each processing element and turns the same update into a fixed-rate pipeline.
