## One equation locates the bottleneck

A four-term model locates the limiting factor in each sweep. The slower of compute and memory sets the time for each serialized wave. Synchronization adds an intra-device barrier cost, while communication adds the time required to move boundary states between devices.

[[FIG:sweep_model]]

The same decomposition covers dynamically scheduled GPUs and statically scheduled FPGAs or ASICs. Its structure stays fixed, although the constants differ by platform. On GPUs, cache residency, achieved bandwidth, and enough resident threads to cover latency determine memory-service time. On streaming platforms, processing elements, clock frequency, initiation interval, and pipeline drain become synthesis-time constants.

A single calibration per GPU predicts performance at block sizes withheld from calibration. The model tracks the measured crossovers because each parameter represents a physical mechanism rather than a curve fitted separately at every operating point.

[[FIG:model_accuracy]]

Physical terms make the model useful for design. A measurement describes one operating point, whereas a calibrated term predicts what changes when the problem grows, the graph degree changes, or another device is added.
